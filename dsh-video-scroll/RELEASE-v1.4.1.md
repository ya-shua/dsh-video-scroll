# dsh-video-scroll v1.4.1

刷B站 + 刷抖音 合并插件（DSH）：一个设置入口 + 浏览器全功能综合面板。

## 亮点
- 合并 c1overzz/dsh-bili-scroll 2.3.1 + NEWJO123/dsh-douyin-scroll 0.5.4，功能原样保留
- 单入口 video-scroll（带 / 的条目名会被 DSH 浏览器端静默丢弃——面板消失根因已修）
- 浏览器综合面板 8390：原装面板复用 + dsw 变量排版修复
- 隐私：启动日志不再记录 key（历史日志已清）
- 配套 snow-video-kit（桌面\插件\snow-video-kit）提供 QQ 智能体工具面与独立工作台

## 安装
dsh plugin --profile desktop add <本插件目录>，重启一次 DSH。
