# 设计 · 阅读线（📖 看小说 / 💬 看贴吧）· 2026-11-07

> 需求来源：使用者要求在刷视频体系里加「看小说」「看贴吧」两条阅读值班线，
> 与刷B站/刷抖音同哲学 —— **她自己看**（真实打开页面读原文，判断以亲眼所见为准），
> **默认关、由使用者在设置里开启**。

---

## 一、目标与非目标

**目标**
1. 她可以追更小说：读最新章节正文，写「追更感想」（人设口吻），进日报与记忆。
2. 她可以逛贴吧：看关注的吧里的新帖，亲自读帖子正文和回复，把有意思的推给主人。
3. 两条线**独立开关**，默认关；贴吧需要**一次性登录**（登录态持久化）。
4. 产出进现有体系：日报落盘 `data/reads/<day>-<kind>.md`、记忆库入库（platform=tieba/novel）、工作台可看。

**非目标（本期不做）**
- 贴吧**发帖/回帖**（只读；发帖涉及账号风控，暂不开放）。
- 小说**付费章节**（只读公开章节；番茄 web 的付费章不对未登录开放）。
- 与值班计划（schedule）联动（v1 手动「跑一轮」；接入峰谷/定时排到下一期）。

## 二、架构

```
snow-video-kit/
├── src/reader-chrome.mjs   ← 浏览器底座（从 douyin/lib/chrome.mjs 移植的核心）
│     · 独立 profile：data/reader-profile（贴吧登录态存这里，不和抖音值班会话抢）
│     · 独立端口段 9434–9473，运行时状态 data/reader-runtime.json
│     · visibleLogin(url)：开一个**可见**窗口让使用者登录一次，cookies 持久化
├── src/reads.mjs           ← 两条阅读线本体
│     · tiebaCollect(吧)     吧页 DOM → 帖子候选（登录墙检测：未登录 → {loginWall:true}）
│     · tiebaRead(帖子url)   帖子 DOM → 主楼+楼层原文
│     · novelToc(书url)      番茄书页 DOM → 书名+章节列表
│     · novelRead(章节url)   章节页 DOM → 正文段落
│     · runReads(cfg, kind)  工具循环：大脑调 read_tieba_thread / read_chapter / read_toc
│                             亲自读 → 输出日报 → 落盘+记忆入库
└── data/reader-profile/    ← 浏览器 profile（不入库）
```

**为什么用真浏览器**：贴吧对裸客户端返回 403（风控），登录墙后内容也只在登录态渲染；
番茄的正文容器（muye-reader-content）由前端渲染。真 Chrome（headless）是唯一稳定通道。

**为什么共享 douyin 底座但独立 profile**：浏览器实例可以复用（同一个 Chrome 开不同站点没冲突），
但贴吧登录态不能写进抖音值班会话的 user-data-dir（两套值班同时跑会互踢）。
移植时改三点：profile 路径、端口段（9434–9473，避开抖音的 9334–9373）、运行时文件位置。

## 三、数据源与约束

| 数据源 | 通道 | 约束 / 风控 | 对策 |
|---|---|---|---|
| 贴吧 吧页 | headless DOM | **未登录 = 登录墙**（帖子列表不渲染）；curl 直接 403 | `visibleLogin` 一次性登录 → cookies 存 profile |
| 贴吧 帖子 | headless DOM | 同上；楼层多时只取前 ~18 楼 | 只读前 18 楼足够判断 |
| 番茄小说 书页/目录 | headless DOM | 公开章节免费可读；付费章不渲染正文 | 只读公开章；书单由使用者给目录页链接 |
| 番茄小说 章节页 | headless DOM | 正文在 `.muye-reader-content`，前端渲染 | DOM 抽取段落，限 24 段/6000 字 |

登录墙的判定：吧页 `li.j_thread_list` 为 0 且页面前段出现「登录」⇒ `{loginWall:true}`，
runReads 返回明确指引（「去 📖 页点贴吧登录」），**绝不编造帖子内容**。

## 四、开关与配置（默认全关）

```jsonc
config.json 新增段（defaults 见 src/config.js）：
"reads": {
  "tiebaEnabled": false,      // 💬 看贴吧 总开关
  "tiebaForums": [],          // 关注的吧名单（吧名，如 "原神"）
  "tiebaPerRound": 3,         // 每轮最多推几帖
  "novelEnabled": false,      // 📖 看小说 总开关
  "novels": [                 // 追更书单
    { "name": "书名", "url": "https://fanqienovel.com/page/<书id>" }
  ]
}
```

- 开关在工作台 **「📖 小说·贴吧」原生页**（规划见 §六）设置区，改完点保存。
- `visibleLogin`（贴吧登录）也从该页触发。

## 五、API（规划）

| 路由 | 方法 | 说明 |
|---|---|---|
| `/api/reads` | GET | 配置 + 最近阅读报告列表 |
| `/api/reads` | POST | 保存 reads 配置段 |
| `/api/reads/run` | POST `{kind:"tieba"|"novel"}` | 跑一轮阅读（同步等待，轮内含多次页面读取） |
| `/api/reads/login` | POST | visibleLogin（开可见窗口登录贴吧/番茄） |
